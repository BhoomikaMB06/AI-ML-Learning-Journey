# Day 3: Python Loops and AI Fundamentals

## Introduction

Loops are important Python programming structures that allow us to repeat instructions. They help us process multiple records efficiently and are useful in data analysis and Machine Learning workflows.

## 1. For Loop

A `for` loop iterates over items in a sequence or values in a range.

```python
for i in range(1, 6):
    print(i)
```

## 2. While Loop

A `while` loop repeats while its condition is true.

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

## 3. Loop Control Statements

- `break`: Stops a loop immediately.
- `continue`: Skips the current iteration.
- Nested loops: Place one loop inside another loop.

## 4. Practical Example

Python loops can process hospital patient arrival counts, calculate totals, and identify periods with high arrivals. These operations introduce the data-processing skills needed for forecasting projects.

## 5. Artificial Intelligence

Artificial Intelligence is the broad field of building systems that perform tasks associated with capabilities such as reasoning, language understanding, and perception.

## 6. Machine Learning

Machine Learning is a branch of AI in which algorithms learn patterns from data to make predictions or decisions.

## 7. Deep Learning

Deep Learning uses multilayer neural networks to learn complex patterns from data.

## 8. Generative AI

Generative AI creates new content, including text, images, audio, and code.

## 9. Data Types for AI

Structured data is organized in a predefined format, often rows and columns. Unstructured data includes images, audio, video, and free-form text. Semi-structured data includes formats such as JSON and XML.

## Conclusion

Python loops help process multiple records without repeating code manually. Understanding loops, conditions, and data structures provides a foundation for learning Pandas, statistics, Machine Learning, Deep Learning, and Generative AI.
